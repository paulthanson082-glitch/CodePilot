# src/ui

Reusable UI components built with an iPad-first design philosophy.

## Principles

- Tap targets ≥ 44 × 44 pt.
- No hover-only interactions.
- Keyboard toolbar support on iPadOS.
- Works equally well with a pointer (mouse/trackpad) and touch.

## Planned contents

- `ToolCard.tsx` — tile component used on the Toolbox Home grid
- `ToolLayout.tsx` — common two-panel layout (input + output) shared by all tools
- `ActionBar.tsx` — Copy / Share / Clear action buttons
- `ErrorBadge.tsx` — inline error highlighting component
